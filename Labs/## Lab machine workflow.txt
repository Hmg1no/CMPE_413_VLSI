## Lab machine workflow

Connect:
  ssh <user>@ite375pcXX.cs.umbc.edu
  /opt/TurboVNC/bin/vncserver
  (new terminal) ssh -XL 59XX:localhost:59XX <user>@ite375pcXX.cs.umbc.edu
  /opt/TurboVNC/bin/vncviewer  -> connect to localhost:XX

New lab setup (once per lab):
  ~/413/cadence/new_lab.sh <labname>

Each session:
  cd ~/413/cadence/CMPE_413_VLSI && git pull
  cp Labs/<lab>/*.vhd ~/413/cadence/labs/<lab>/
  cd ~/413/cadence/labs/<lab>
  ./launch_cadence_xrun.sh -top <top> <files...> -input sim.run -access +rwc

sim.run contents:
  run <N> ns
  exit
